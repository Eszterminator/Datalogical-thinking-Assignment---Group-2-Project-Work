Dataset Overview

Our project utilizes a structured dataset extracted from Goodreads, sourced via Kaggle. The dataset provides comprehensive metadata on various popular literary works, giving our algorithm sufficient data points to evaluate reader satisfaction, categorization, and physical volume.

To satisfy the core project constraints, our curated dataset maintains over 50 well-formed entries, stored in tabular .csv format for direct algorithmic reading.

Data Structure & Attributes

The primary columns retained for the recommendation and pacing algorithm include:

Attribute Data Type Description
book_id Integer Unique identifier for each record
title String The full title of the publication.
author String The author credited for the work.
average_rating Float Average reader score on a scale from 1.0 to 5.0.
rating_count Integer Count of user ratings the average is calculated from
page_count Integer Total page count used for reading pace estimation.
year Integer Year of publication of the book
genre String The categorical classification of the book.

Genre Distribution & Selection

When inspecting the original dataset, we audited the distribution of records across categories to ensure our algorithm could return a reliable list of top recommendations:

  • Classics: 76 records
  • Fiction: 37 records
  • Fantasy: 32 records
  • Young Adult: 18 records
  • Childrens: 11 records
  • Historical: 6 records
  • Science Fiction: 4 records
  • Cultural: 1 record

Based on these counts, we decided to focus primarily on Classics, Fiction, Fantasy, and Young Adult, as they provided sufficient entries to support a robust "Top 10" recommendation query.

Design Justifications & Cleaning

Format Selection: We chose CSV due to its widespread compatibility, lightweight nature, and seamless parsing capabilities in spreadsheet software and automated programming scripts.

Data Modeling Choices: Rather than performing manual cross-table joins across separate rating files, we selected an aggregated record model featuring average_rating directly. This keeps the algorithm concise, modular, and focused on user-driven filtering.

Dataset Preparation: We added unique book IDs from 1 to 163 to identify each record. The final dataset contains 163 books and eight columns: book_id, title, author, average_rating, rating_count, page_count, year, and genre. The rating_count column is retained in the dataset but is not displayed in the recommendation output. The project focuses on four genres: Fantasy, Classics, Fiction, and Young Adult. The prepared CSV file is stored in the project's GitHub repository for use by the Python algorithm.

Data Cleaning Example: We corrected inconsistencies discovered during our data audit. For instance, Crime and Punishment was originally classified under the single-entry label "Cultural" and was reclassified into "Classics" to ensure correct categorization. We also corrected the misspelled column name "authour" to "author", fixed encoding issues affecting special characters in authors' names, and standardized the column names by changing "name" to "title" and "rating" to "average_rating". The file was reformatted as a comma-separated CSV file. We checked for missing values, duplicate book IDs, non-positive page counts, and ratings outside the 0–5 range; none were found.

Dataset Limitations & Future Work

  • Single Genre Classification: Each book in our current dataset is assigned to a single genre, whereas literary works often span multiple categories. Creating a relational database where several genres could be linked to each title would be a natural next step to improve recommendations.
  • Dataset Age & Static Ratings: The dataset originates from historical Kaggle records uploaded several years ago. Since reader reviews on Goodreads fluctuate over time, the current live ratings will differ from our static figures.
  • Sample Size & Catalog Representation: Our curated dataset represents a focused sample rather than the full Goodreads catalog. Consequently, the user is unaware whether a top-rated recommendation was selected from a pool of 15 titles or 500 titles within that category.
