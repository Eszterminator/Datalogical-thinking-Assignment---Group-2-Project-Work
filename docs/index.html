About The Project

Finding the right book to read next can often be overwhelming given the vast amount of literature available online. This project addresses that challenge by combining curated reader feedback with personalized pacing metrics.

Using a structured dataset of popular books from Goodreads, our goal is to help users discover highly rated titles within their preferred genre while estimating the time commitment required based on their personal daily reading pace.

Our Core Approach

1. Curated Data

We extract and clean metadata from Goodreads, including titles, authors, genres, average ratings, and page counts, ensuring a clean, structured foundation for algorithmic processing.

2. Algorithmic Recommendations

Our algorithm filters titles based on reader preferences and user constraints, ranking books by rating and calculating realistic reading completion timelines.

3. Transparent Documentation

We document the complete pipeline — from Kaggle data wrangling to pseudocode logic and responsive web presentation — demonstrating core principles of datalogical thinking.
