Dataset Overview

Our project utilizes a structured dataset extracted from Goodreads, sourced via Kaggle. The dataset provides comprehensive metadata on various popular literary works, giving our algorithm sufficient data points to evaluate reader satisfaction, categorization, and physical volume.

To satisfy the core project constrains, our curated dataset maintains over 50 well-formed entries, stored in tabular .csv format for direct algorithmic reading.

Data Structured & Attributes

The primary columns retained for the recommendation and pacing algorithm include:

Attribute Data Type Description
title String The full title of the publication.
authors String The primary author(s) credited for the work.
genre String The categorical classification of the book.
average_rating Float Average reader score on a scale from 1.0 to 5.0.
num_pages Integer Total page count used for reading pace estimation.

Design Justifications & Cleaning

Format Selection: We chose CSV due to its widespread compatibility, lightweight nature and seamless parsing capabilities in both tabular spreadsheet editors and algorithmic loops.

Data Modeling Choices: Originally, community review files contained disaggregated individual user ratings. We opted for an aggregated model featuring average_rating and num_pages directly in the primary record. This simplification avoids redundant join operations, keeps our algorithm concise (under 50 lines), and retains only the attributes strictly required to address our project's user query.
