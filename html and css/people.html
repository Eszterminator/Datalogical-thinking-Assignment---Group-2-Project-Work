Project Team & Roles

This project was developed collaboratively by Group 2 for the Datalogical Thinking course. To ensure a balanced distribution of labor and clear accountability, each team member took primary ownership of a core component while contributing to collective reviews and discussions.

  • Audited records, checked formatting consistency, and filtered irrelevant attributes.
  • Cleaned categorical fields and maintained the structured CSV data file in the repository.

Ana Catarina Fernandes

Collaborative Workflow & Commit History

Beyond primary roles, all members participated actively in cross-checking deliverables:

  • Decisions regarding genre scope (focusing on Classics, Fiction, Fantasy, and Young Adult) and algorithm filters were made collaboratively.
  • GitHub was utilized as the central hub for incremental commits, peer code review, and version control.
  • Group check-ins and asynchronous communication ensured consistent progress across the data, algorithmic, and web phases.
